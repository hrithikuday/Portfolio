# Hrithik Uday - Personal Portfolio Website

Welcome to the repository for my personal portfolio website. This project is a modern, high-performance, and visually stunning digital experience designed to showcase my journey, skillset, and projects.

Built using **Next.js**, **React**, **Framer Motion**, and **Tailwind CSS**, this portfolio incorporates premium glassmorphic UI design, smooth micro-animations, and complete responsive control.

---

## 🌟 Key Features

*   **Premium Glassmorphic Design**: Clean modern aesthetic incorporating subtle gradients, Harmonious color styling, borders, and depth effects.
*   **Fluid & Interactive Animations**: Smooth page entries, interactive hover movements, and custom spring-based transitions powered by Framer Motion.
*   **Optimal Performance**: Leverages Next.js server-side features, font/asset optimizations, and lazy rendering techniques.
*   **Fully Responsive**: Meticulously structured layouts that adapt flawlessly to mobile, tablet, and desktop screens.
*   **Comprehensive Project Showcases**: Features modular cards with interactive links to live deployments and source code repositories.

## 💻 Getting Started Locally

Follow these steps to run a development instance of this portfolio on your system:

### 1. Prerequisites
Make sure you have Node.js (version 18+ recommended) and npm installed.

### 2. Clone the Repository
```bash
git clone https://github.com/hrithikuday/Portfolio.git
cd Portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 5. Build for Production
To build a production-ready application bundle:
```bash
npm run build
npm run start
```
